## 🎯 Tujuan Pembelajaran

Setelah mengikuti pertemuan ini, mahasiswa diharapkan mampu:

1. Meninjau kembali implementasi berbagai protokol komunikasi (HTTP & MQTT)
2. Memahami integrasi antara mikrokontroler dengan berbagai platform (Web & Android)
3. Mendapatkan inspirasi untuk pengembangan proyek tugas akhir (Final Project)
4. Menganalisis kelebihan dan kekurangan tiap metode implementasi

---

## 📚 Materi Pokok

### 1. Showcase Proyek IoT

Pertemuan terakhir ini berfokus pada demonstrasi dan workshop implementasi sistem IoT yang utuh. Terdapat tiga variasi utama yang sering digunakan dalam proyek profesional maupun akademik.

#### A. Proyek 1: Smarthome dengan MQTT dan Website
Sistem ini menggunakan website sebagai antarmuka utama. Keunggulannya adalah aksesibilitas tinggi melalui browser di perangkat apa pun dan respon real-time yang sangat cepat.

#### B. Proyek 2: Smarthome dengan MQTT dan Android (Kodular)
Sistem ini menggunakan aplikasi Android native (dibuat dengan platform Kodular atau MIT App Inventor). Sangat user-friendly untuk kontrol perangkat rumah tangga melalui smartphone dengan notifikasi push.

#### C. Proyek 3: Implementasi dengan Website dan REST API
Sistem ini menggunakan protokol HTTP standard. Sangat stabil untuk pengiriman data historis ke database dan lebih mudah dikembangkan menggunakan framework web modern.

## 📌 Tips Proyek Final

1. **Tentukan Masalah:** Mulailah dari masalah nyata yang ingin diselesaikan.
2. **Pilih Protokol:** Gunakan MQTT jika butuh kecepatan (*real-time*), gunakan HTTP jika fokus pada *data logging*.
3. **Keamanan:** Jangan lupa tambahkan otentikasi (username/password) pada broker MQTT atau API key pada REST API.
4. **Dokumentasi:** Catat diagram rangkaian dan alur program dengan jelas.
