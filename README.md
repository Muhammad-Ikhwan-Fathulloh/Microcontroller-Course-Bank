## 13. 🤖 Robotika: Mobile Robot
**Deskripsi:** Proyek pengembangan **mobile robot** dengan konfigurasi **4 roda omniwheel** yang dikendalikan melalui **ESP32** dan protokol **MQTT**. Robot ini dirancang untuk navigasi omnidirectional (bergerak ke segala arah) dengan kontrol presisi.
- **Komponen Utama:** ESP32, 2x Modul Driver Motor L298N, 4x Motor DC dengan Omniwheel, Baterai Li-Ion 7.4V/12V.
- **Fitur Utama:**
    - ✅ **Kontrol penuh arah:** maju, mundur, geser kiri/kanan, berputar (rotasi).
    - ✅ **Komunikasi MQTT:** Menerima perintah melalui topik `robot/control` dan mengirim status pada topik `robot/status`.
    - ✅ **Auto Reconnect:** Koneksi WiFi dan MQTT otomatis kembali jika terputus.
    - ✅ **Beberapa Varian Kode:** Tersedia versi dengan PID, penghindar halangan (obstacle avoidance), dan kontrol lokal.
- **Koneksi Hardware:** Menggunakan dua driver L298N (masing-masing untuk 2 motor kiri dan 2 motor kanan) dengan konfigurasi pin ESP32 yang lengkap.
- **Cara Penggunaan:** Kirim perintah MQTT sederhana (`forward`, `left`, `turn_right`, dll.) dari aplikasi seperti MQTT Explorer atau IoT MQTT Dashboard.
- **Repositori & Proyek:**
    - 📁 [Repositori GitHub - KoKuBot (Mobile Robot)](https://github.com/Muhammad-Ikhwan-Fathulloh/KoKuBot) *(Berisi kode sumber untuk berbagai fitur, diagram koneksi hardware, dan dokumentasi lengkap)*
    - 🌐 [Halaman Proyek KoKuBot](https://ikhwanfathulloh.netlify.app/kokubot)
